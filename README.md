# financial-sentiment-analysis
A real-time market prediction project using Yahoo Finance data, sentiment analysis, RNN, LSTM, and GRU models for trend and volatility prediction.

# Real-Time Market Movement Prediction System

## Overview
This project predicts financial market movements using sentiment analysis and sequential deep learning models such as RNN, LSTM, and GRU.

## Objectives
- Collect financial news and market data
- Perform sentiment analysis
- Train deep learning models
- Predict market trends and volatility

## Technologies Used
- Python
- TensorFlow
- Pandas
- NumPy
- Scikit-learn

## Models
- RNN
- LSTM
- GRU

## Evaluation Metrics
- Accuracy
- F1-Score
- RMSE
